02 Key Engineering Decisions

의사결정 1 · 생성형 AI 단일 판정 대신 경량 분류 모델 + 규칙 + URL 평판 하이브리드
제약 조건
GPU 없는 CPU 추론 서빙, 외부 API(Gemini·VirusTotal) 키 미설정·호출 실패 가능성
대안 비교
Gemini 단일 판정 vs 로컬 KLUE BERT 분류 + 규칙 NLP + URL 위협 인텔리전스 + Gemini 보조 신호
최종 선택
카테고리 신호는 로컬 INT8 모델로 고정, 생성형 AI는 보조 점수(P_Gemini·P_VLM)로 한정 → Gemini 미가용 시에도 OCR·규칙·URL 결과만으로 응답 반환. INT8 전환 정확도 손실 −0.11%p 수준에서 지연 절반 단축
의사결정 2 · 모델 배포·위협 데이터 갱신 파이프라인
문제 상황
대용량 가중치 저장소 포함 불가, 위협 피드·악성 URL 상태의 시간 경과에 따른 노후화
해결 설계
서버 기동 시 로컬 캐시 확인 후 Hugging Face에서 INT8 가중치·config·tokenizer만 다운로드, revision 커밋 해시 고정으로 재현성 확보. 위협 피드 6시간 주기 갱신, 위험 URL 랭킹 상위 항목 주간 재검사

03 Production Bottlenecks & Troubleshooting

Issue 1 · CPU 단일 추론 지연 및 모델 용량 병목
Root Cause
FP32 BERT 체크포인트 426.58 MiB, 단일 메시지 p50 370.97 ms / p95 449.58 ms로 공개 API 동시 요청 처리 한계
Engineering Action
PyTorch INT8 동적 양자화 state_dict 배포, 분석 작업을 최대 4개 ThreadPoolExecutor 워커로 격리, X-Analysis-ID 기반 협력 취소 지원, IP·경로별 요청 제한(이미지 10회/분, 텍스트 30회/분, 피드백 20회/분)
Impact
모델 크기: 426.58 → 178.56 MiB (−58.14%) p50: 370.97 → 196.40 ms (−47.1%) p95: 449.58 → 220.32 ms (−51.0%)
Issue 2 · AI·외부 신호 불확실성 및 악성 입력 방어
Root Cause
OCR 인식 실패, Gemini 호출 실패·미설정, 분류 확률 ≠ 스미싱 확률, 악성 URL 추적 시 내부망 요청(SSRF) 위험
Engineering Action
텍스트·URL 모두 미추출 시 Unknown + ocr_failed 반환. Gemini 점수 null 처리 후 가용 신호 기반 가중치 분기. URL 강한 의심·정부기관 사칭 조건 시 등급 하한 보정. 리다이렉트 최대 5회, 매 단계 사설·루프백·링크-로컬 IP 및 인증정보 포함 URL 차단. VirusTotal 미등록은 안전이 아닌 정보 부족으로 처리. 이미지 10 MiB·25,000,000 px, 텍스트 20,000자, 요청당 URL 10개 상한 적용
