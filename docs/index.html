05 — AI ENGINEERING

RESEARCH.

모델 성능을 높이는 일만큼, 무엇을 검증했는지 정확히 설명하는 일을 중요하게 생각합니다.

CASE STUDY / CatchSmishing

높은 숫자보다
신뢰할 수 있는 평가.

초기 무작위 분할 평가에서 동일 문장이 학습·평가 데이터에 걸쳐 존재할 수 있다는 문제를 확인했습니다. 이를 해결하기 위해 120개 하위 유형을 기준으로 데이터를 그룹 분리하고, 증강 데이터를 학습에만 사용한 뒤 중복 검사를 진행했습니다.

그 결과 새로운 그룹 분할 조건에서 3회 학습 시드 평균 정확도 96.18%, Macro-F1 96.15%를 기록했습니다.

실험과 구현 확인하기 ↗
01 / MODEL EVALUATION96.18%

7개 문자 유형 분류 정확도 · 그룹 분할 평가

02 / QUANTIZATION−58%

FP32 대비 INT8 모델 파일 크기 감소

03 / INFERENCE−47%

로컬 벤치마크의 단일 문자 p50 지연 감소

평가 결과는 특정 데이터·실험 조건에 한정되며, 정상/스미싱 이진 탐지율 및 독립적인 실사용 성능과 구분합니다.
